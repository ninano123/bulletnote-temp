하루 불릿저널 템플릿

개요

하루 단위 기록을 중심으로, 불릿저널을 운영하는 데 필요한 페이지를 분류해 템플릿으로 만듭니다.

하루 중심

데일리 페이지가 핵심입니다. 월간·주간·트래커 페이지는 데일리 기록을 받쳐 주는 역할을 합니다.

HTML로 작성

모든 템플릿은 HTML 문서입니다. 브라우저에서 열어 바로 확인하고, 수정하고, 내보낼 수 있습니다.

고정 비율

태블릿 화면과 인쇄 용지에 맞춘 여러 비율을 제공합니다. 노트 앱으로 가져와도 여백이 어긋나지 않습니다.

미니멀 그레이

회색 선과 여백 위주로 디자인합니다. 손글씨와 색 펜을 쓸 자리를 남겨 둡니다.

사용법

템플릿을 골라 태블릿 노트 앱으로 옮기기까지의 순서입니다.

  1. 템플릿 고르기템플릿 분류에서 필요한 페이지를 찾아 엽니다.
  2. 비율 고르기쓰는 태블릿에 맞는 비율을 선택합니다. 잘 모르겠다면 지원 비율 표를 참고하세요.
  3. PDF로 내보내기브라우저 인쇄(Ctrl/⌘ + P) → "PDF로 저장"을 선택합니다. 여백은 "없음", 배경 그래픽은 "켜기"로 설정합니다.
  4. JPG로 내보내기템플릿 페이지의 JPG 버튼을 누르면 위 표에 적힌 픽셀 크기로 저장됩니다.
  5. 노트 앱에 넣기PDF는 문서로 가져오거나, 노트 앱의 "사용자 템플릿/속지"로 등록해 매일 새 페이지로 추가해 씁니다.

하루 흐름

데일리 템플릿을 하루 동안 어떤 순서로 쓰는지 보여 줍니다.

MORNING

계획

타임박스 플래너에 할 일 3~6개를 적고 시간 블록에 배치합니다.

DAYTIME

기록

래피드 로그 페이지에 할 일·이벤트·메모를 기호와 함께 바로 적습니다.

EVENING

회고

데일리 회고에 감사, 잘한 일, 기분을 적고 트래커를 채웁니다.
