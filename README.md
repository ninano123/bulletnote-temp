# 하루 불릿저널 템플릿

태블릿에서 쓰는 불릿저널 속지 템플릿 모음입니다.

모든 템플릿은 HTML로 만들어져 있습니다. 브라우저에서 열고 비율(ISO A · 3:4 · 10:16 · Letter)을 고른 뒤 PDF나 JPG로 내보내 GoodNotes, Notability, Samsung Notes 같은 노트 앱에서 쓸 수 있습니다.

데일리, 기간 로그, 트래커, 컬렉션, 회고, 설정, 속지로 나뉘어 있고, 양식마다 여러 디자인을 제공합니다.

[나만의 불릿저널 만들기](docs/builder.html)에서는 목적과 단계별 선택에 따라 한 권의 저널을 구성해 한 번에 내보낼 수 있습니다.

시작 페이지는 [docs/index.html](docs/index.html)입니다.
